# CosmoHaven — Game Design & Requirements Spec

เอกสารนี้อธิบาย **concept ของเกม**: เรื่องราว ธีม แกนการเล่น ระบบที่ทำแล้ว และข้อจำกัด
เพื่อให้ใครหยิบโปรเจกต์ขึ้นมาก็เข้าใจว่าเกมนี้คืออะไรและทำไมถึงออกแบบแบบนี้

- รายละเอียดสถาปัตยกรรม/ตัวเลข: [KNOWLEDGE.md](KNOWLEDGE.md)
- เช็กลิสต์งาน: [PLAN.md](PLAN.md)
- วิธีรัน/ปุ่มควบคุมโดยย่อ: [../README.md](../README.md)

> **หมายเหตุเรื่องเนื้อเรื่อง:** ตัวเกมไม่มีบทสนทนาหรือฉากเล่าเรื่อง เนื้อเรื่องในหัวข้อ 2 เป็น
> *narrative framing* ที่สรุปจากกลไกที่มีในเกม (Earth 2.0, Signal Relics, Space-Fold, ลูกเรือหลายเผ่า)
> เพื่อเป็นกรอบให้ทีมใช้ตัดสินใจเรื่องดีไซน์ ไม่ใช่ canon ที่ล็อกแล้ว แก้ได้ตามต้องการ

## 1. สรุปหนึ่งย่อหน้า (Pitch)

CosmoHaven คือเกมสำรวจอวกาศ 3 มิติบนเว็บเบราว์เซอร์ ผู้เล่นสร้างยานทีละบล็อกที่ท่าเรืออู่ลอยฟ้า
(drydock) ดูแลลูกเรือตัวการ์ตูนน่ารักให้มีชีวิตรอด เก็บ Scrap และ Signal Relics ในดาวต่าง ๆ แล้วใช้
เครื่องยนต์ Space-Fold กระโดดข้ามระบบดาวที่สุ่มสร้างขึ้น เป้าหมายสุดท้ายคือหา **Earth 2.0**
และลงจอดบนผิวดาวอย่างนุ่มนวลเพื่อตั้งบ้านใหม่ให้ลูกเรือ

**คีย์เวิร์ด:** cozy space survival · shipbuilding · เล่นเป็นยานจริงด้วยฟิสิกส์ 6-DOF · โลกเปิดแบบ procedural · ศิลปะ clay/toon แบบ Animal Crossing

## 2. ที่มาและเรื่องราว (Origin & Story)

### 2.1 ที่มาของโปรเจกต์
โปรเจกต์เริ่มจากโจทย์ "ยานอวกาศที่ผู้เล่นต่อเองได้" และค่อย ๆ เติมเป็นเฟสต่อเนื่อง:
ต่อยาน/ฟิสิกส์ → ลูกเรือ AI → โหมดและอุกกาบาต → เศรษฐกิจและเป้าหมาย Earth 2.0 → บังคับยาน 6 แกน →
แรงโน้มถ่วงดาว → เก็บทรัพยากร + autopilot → Space-Fold/โลกเปิด → ปรับภาพ → สถานีอวกาศและอู่ต่อยาน →
orbit/landing → target lock → เผ่าพันธุ์ลูกเรือ → ปรับสไตล์ตัวละครให้นุ่มนิ่มแบบ Animal Crossing

ทิศทางดีไซน์ค่อย ๆ เปลี่ยนจาก "เกมต่อบล็อกง่าย ๆ" ไปเป็น **space simulator ที่จริงจังขึ้นแต่ยังอบอุ่น**:
ต้องจอดที่ drydock ถึงจะแก้ไขยานได้, การลงดาวต้องคุมความเร็ว, แรงโน้มถ่วงและบรรยากาศมีผลจริง

### 2.2 เรื่องราว (narrative framing)
โลกเดิมอยู่ไกลเกินกลับ ลูกเรือกลุ่มเล็ก ๆ จากหลายเผ่าพันธุ์ออกจาก **Haven Drydock** สถานีอู่ต่อยาน
ที่โคจรรอบดาว Kepler-9 ด้วยยานที่ประกอบเองจากเศษโลหะ พวกเขาเชื่อใน "Earth 2.0" ดาวบ้านใหม่ในตำนาน
ซึ่งไม่มีพิกัดที่แน่ชัด พิกัดถูกซ่อนอยู่ใน **Signal Relics** ที่กระจายอยู่ในแต่ละระบบดาว
ต้องเก็บให้ครบ 5 ชิ้นจึงถอดรหัสได้ และเดินทางไปยังได้เฉพาะด้วย Space-Fold

ลูกเรือไม่ใช่แค่ตัวเลข: พวกเขาหิว เครียด เล่นเกมตู้ ทำอาหาร ซ่อมยาน และเดินไปมาในห้องที่ผู้เล่นสร้าง
ผู้เล่นคือทั้งวิศวกรผู้สร้างยาน กัปตันผู้บังคับยาน และผู้ดูแลความเป็นอยู่ของครอบครัวบนยานลำเดียวกัน
การสร้าง Engine, Shield Generator และ Repair Bay ช่วยให้ผู้เล่นปรับสมรรถนะยานและให้ลูกเรือซ่อม Hull ได้

### 2.3 อารมณ์ที่อยากให้ได้
- **เหงาแต่อบอุ่น** — อวกาศกว้างใหญ่ แต่ในยานมีชีวิตและเสียงหัวเราะ
- **ความสำเร็จจากฝีมือ** — ลงจอดสำเร็จเพราะเบรกทัน ไม่ใช่เพราะกดปุ่มเดียว
- **ตื่นตาตอนเข้าใกล้** — ดาวใหญ่ขึ้น บรรยากาศเรืองแสง ไฟลุกตอน re-entry

## 3. ธีมและทิศทางศิลป์ (Theme & Art Direction)

| ด้าน | แนวทาง |
|---|---|
| อวกาศ | ฉากหลัง nebula (GLSL shader), ดาวพื้นหลัง, ดวงอาทิตย์ที่ให้แสงและเงาจริง |
| แสง | HDR emissive + Bloom + ACES tone mapping (`<Canvas flat>`), ชั้นบรรยากาศแบบ Fresnel |
| ดาว | texture วาดด้วย canvas แบบ procedural (ไม่ใช้ไฟล์ภาพ), ก้อนเมฆ, Earth 2.0 มีมหาสมุทรและทวีป |
| ยาน | บล็อกมีห้องภายใน มองเข้าไปเห็นลูกเรือ (กด `V` สำหรับ interior view) |
| ตัวละคร | สไตล์ clay แบบ Animal Crossing: หัวโต หน้ามีไฮไลต์ตา แก้มแดง `MeshToonMaterial` + gradient map, เด้งตัวเบา ๆ ขณะเดิน |
| UI | HUD แบบ sci-fi โปร่งใสสีฟ้า/มินต์ ส่วนหน้าจอสร้างตัวละครใช้โทนส้ม-พีชอุ่น ๆ ตัดกับอวกาศ |

หลักคิด: **โลกภายนอกสมจริง/ยิ่งใหญ่ ส่วนภายในยานนุ่มนิ่มน่ารัก** เพื่อสร้างความต่างที่ทำให้ยานรู้สึกเป็น "บ้าน"

## 4. แกนการเล่น (Core Loop)

```
เก็บวัตถุดิบ ──► ขายเป็น Haven Credits (HC) ──► ต่อ/ขยายยานที่ Drydock
     ▲                                          │
     │                                          ▼
  ซ่อมยาน / ดูแลลูกเรือ ◄── เจอ Signal Relic ◄── Space-Fold ไประบบดาวใหม่
                                                │
                              ครบ 5 Relics ─────┘
                                                ▼
                         Sector ของ Earth 2.0 ─► ลงจอดอย่างนุ่มนวล (<12 u/s) = ชนะ
```

**จังหวะการเล่นระดับสั้น:** บินไปหา Scrap → เปิด tractor beam (`F`) → หลบอุกกาบาต (ทุก 15–20 วินาที) →
เข้าเขตแรงโน้มถ่วงดาว → เลือก orbit หรือ landing

**ระดับกลาง:** เก็บวัตถุดิบจนโกดังใกล้เต็ม → ขายที่ Trade Relay/drydock → ต่อบล็อก/อัปเกรด → Fold

**ระดับยาว:** ครบ 5 Relics → Earth 2.0 unlock → ลงจอดสำเร็จ

## 5. ระบบในเกม (Feature Spec)

สถานะ: ✅ ทำแล้ว · ⚠️ ทำแล้วแต่มีข้อจำกัด

### 5.1 สร้างยาน (Shipbuilding) ✅
- ต่อยานจากบล็อก ด้วยการคลิกหน้าบล็อกเพื่อเพิ่ม, Shift+คลิกเพื่อรื้อ
- บล็อก: **Hull** (10 HC), **Food Dispenser** (30), **Arcade** (30), **Engine Module** (60), **Shield Generator** (80), **Repair Bay** (70); ราคาได้รับตัวคูณตาม difficulty
- Engine แต่ละบล็อกเพิ่ม thrust 25% (สูงสุด 4 บล็อก); Shield แต่ละบล็อกลดความเสียหายจากการชน 20% (สูงสุด 3 บล็อก)
- เมื่อ Hull ต่ำกว่า 75% ลูกเรือจะเดินไปใช้ Repair Bay เพื่อซ่อม 5 Hull/วินาที; ต้องมีลูกเรือและห้องที่เข้าถึงได้
- Shipyard แสดงผลของ module แต่ละชนิด; ใช้ปุ่ม 1–6 เลือกบล็อก (remap ได้ใน Settings) หรือ Q วนชนิดบล็อก
- การก่อสร้างผ่านคิวโดรน มีโฮโลแกรมแสดงชิ้นที่รอสร้าง
- **แก้ไขยานได้เฉพาะตอนจอดที่ drydock** (ปุ่ม `M` แจ้งเตือนถ้าลองนอกอู่)
- ยานเป็น compound body: จุดศูนย์กลางมวลและโมเมนต์ความเฉื่อยคำนวณจากรูปทรงที่ต่อ
- เสียบล็อกหายเมื่อชนแรง (ความเร็วชน >12 u/s, ความเสียหาย >30 อาจทำบล็อกหลุด)

### 5.2 ลูกเรือและเผ่าพันธุ์ (Crew & Species) ✅
- สร้างตัวละครก่อนเริ่ม: ชื่อ, เผ่า, ตัวเลือกรูปลักษณ์เฉพาะเผ่า, อาชีพเริ่มต้น พร้อม preview 3D หมุนได้
- **5 เผ่า:** Human, Felinian, Jelly, Synth, Floran — แต่ละเผ่ามี trait (เช่น หิว/เครียดช้าเร็วต่างกัน,
  Jelly ซ่อมตัวยาน, Floran สังเคราะห์แสง ต้องอยู่ในที่สว่าง)
- **3 อาชีพ:** Engineer, Pilot, Chef — ให้โบนัสต่างกัน: Engineer +10% ความเร็วก่อสร้าง, Pilot +10% ความเร็วยาน, Chef อาหารฟื้น Hunger มากขึ้น 50%
- AI ลูกเรือ: A* pathfinding ในยาน, wander/เดินไปใช้ Food Dispenser/Arcade ตามความต้องการ และ Repair Bay เมื่อ Hull ต่ำกว่า 75%
- ค่าสถานะ **Hunger** และ **Sanity** ลดลงตามเวลา; Arcade ฟื้น Sanity, Food Dispenser ฟื้น Hunger
- ต่ำกว่า 40 ลูกเรือจะเดินไปหา Food Dispenser/Arcade และฟื้นค่าเมื่อใช้บล็อก; ถ้าไม่มีบล็อกจะแสดงสถานะใน HUD แต่ Hunger/Sanity ที่ 0 ยังไม่มี penalty ต่อ Hull/ความเร็วโดยตรง
- ลูกเรือไม่พังเมื่อผู้เล่นรื้อบล็อก (หาที่ยืนใหม่ได้)

### 5.3 การบินและฟิสิกส์ (Flight & Physics) ✅
- ฟิสิกส์ผ่าน cannon (worker): บิน 6 แกน (thrust, strafe, yaw, pitch, roll) + เมาส์ดูทิศทาง (pointer lock)
- แรงและแรงบิดถูกปรับตาม frame time จึงให้ผลเหมือนกันทุก FPS
- กล้อง: chase / orbit (`C`) / interior (`V`) / docked
- ความเสียหายตัวยาน (Hull 0–100%): ยิ่งเสียหาย thrust ยิ่งลด (เหลือ 55% ที่ 0%)
- ที่ Hull 0 ยานยังบินได้ด้วย thrust 55%; ปัจจุบันไม่มี Game Over state
- ซ่อมโดยลูกเรือที่ Repair Bay เมื่อ Hull ต่ำกว่า 75%; ซ่อมฟรีที่ shipyard หรือฉุกเฉินด้วย HC (`R`, 15 HC, +25%)

### 5.4 แรงโน้มถ่วง บรรยากาศ และการมาถึงดาว (Gravity & Arrival) ⚠️
- แรงโน้มถ่วงแบบ gm/r² มี fade ที่ขอบ well; วงโคจรเสถียรเฉพาะในรัศมี < 75% ของ well
- บรรยากาศมี drag และแรงปั่นป่วน; re-entry มีเอฟเฟกต์ไฟและความร้อน
- **Arrival state machine:** none → choice → insertion → orbiting → deorbit → descent → landed
  - `O` เข้าวงโคจร, `L` เริ่มลงจอด; ลงจอดปลอดภัยต้องความเร็ว ≤ 12 u/s
  - ระหว่าง descent มีคันเร่งเบรก (Space/Shift)
- ⚠️ ที่ความเร็วสูงมากมาก ๆ การเข้าวงโคจรดาวเล็กอาจไม่สำเร็จ

### 5.5 เก็บทรัพยากร (Harvesting) ✅
- Tractor beam (`F`) ดึง Scrap ลอยในอวกาศ; 3 tier: T-Beam (ระยะ 10), Magnetic Scoop (22, ดูดอัตโนมัติ, 80 Scrap), Quantum Harvester (55, 200 Scrap)
- วัตถุดิบที่เก็บกินพื้นที่จริงใน cargo hold; ความจุเริ่มต้น 8 units และห้ามเก็บเมื่อเต็ม
- เปิด Trade Relay ได้ทุก sector (ขาย 18 HC ต่อ Scrap) หรือขายที่ drydock ในราคาเต็ม (20 HC); Scrap ต้องขายก่อนจึงใช้จ่ายได้
- เริ่มเกมด้วย 100 **Haven Credits (HC)**; Relics ใช้พื้นที่ 1 unit และขายไม่ได้
- อัปเกรด Harvester (`U`: Magnetic Scoop 80 HC, Quantum Harvester 200 HC) และ Auto-Pilot (`I`: Advanced 120 HC, Expert 250 HC)
- Cargo technologies ซื้อด้วย HC: Expanded Bay (14 units, 120), Mass Compressor (8 units, cargo ใช้ 55% volume, 240), Quantum Vault (12 units, cargo ใช้ 30% volume, 450); เปลี่ยนระหว่างที่ซื้อไว้แล้วได้ฟรี

### 5.6 Autopilot และงานอัตโนมัติ ✅
| Tier | ความสามารถ |
|---|---|
| 1 Basic | บินไปยัง waypoint พร้อมเบรกอัตโนมัติ |
| 2 Advanced | หลบอุกกาบาตโดยทำนายจุดเข้าใกล้ที่สุด |
| 3 Expert | เผาเครื่องแบบประหยัดเชื้อเพลิง และล็อกเข้าวงโคจรดาวได้ |

งาน (task) ที่สลับด้วย `Shift+P`: **NAV, HARVEST, HOLD, EVAC** และงานที่สั่งจาก context menu
คือ **ORBIT, LAND, DOCK**

### 5.7 Target lock และเมนูบริบท ✅
- คลิกที่วัตถุ (ดาว, สถานี, Scrap, Relic, อุกกาบาต) หรือ `T` เพื่อวนเป้าหมาย
- กรอบล็อกบนหน้าจอพร้อม telemetry; เมนูบริบทสั่ง action ด้วยเมาส์หรือเลข `1–4`
- ⚠️ ขณะอยู่ pointer lock (chase view) คลิกวัตถุไม่ได้ ใช้ `T`/เลข หรือกด `Esc` ก่อน

### 5.8 Space-Fold และโลกเปิดแบบ procedural ✅
- `J` กระโดดไปยัง sector ใหม่ (40 HC) ผ่านขั้นชาร์จ → แฟลช → มาถึง
- Sector สร้างจาก seed (mulberry32): ดาวเคราะห์, ดวงดาว, Scrap, Relic — seed เดิมได้ผลเดิม
- Sector พิเศษ: **Home** (Kepler-9 + Haven Drydock) และ **Earth** (ปลดล็อกเมื่อมี 5 Relics)
- Signal Relic: ชิ้นเดียวต่อ sector ที่ fold ไปเจอ มีตัวชี้ระยะ

### 5.9 สถานีอวกาศและการ dock ✅
- Haven Drydock: เส้นทางเข้าโดยโค้ง Bezier เข้าโรงเก็บ (hangar เปิดด้าน +Z)
- เงื่อนไข dock: ระยะ ≤ 50 และความเร็ว ≤ 20; ใช้เวลา 3 วินาที (ปุ่ม `E`)
- ระหว่าง dock ยานถูกตรึง (mass = 0) และเปิดหน้า Shipyard

### 5.10 เป้าหมายและชัยชนะ ✅
- เก็บ **5 Signal Relics** → ปลดล็อก Earth 2.0 ที่ตำแหน่ง `[0, 0, −1700]` ในเซกเตอร์ของมัน
- **ชนะเมื่อแตะพื้นอย่างปลอดภัย** (≤ 12 u/s) ไม่ใช่แค่บินเข้าใกล้
- Earth 2.0 เป็นวัตถุแข็งจริง มี collider; ชนแรงก็เสียหาย

### 5.11 ภัยอันตราย ✅
- อุกกาบาตเกิดทุก ๆ 15–20 วินาที มีคำเตือนบน HUD และ autopilot tier 2 หลบได้
- ชนแรงทำให้ Hull ลดและอาจเสียบล็อก

### 5.12 Pause และการควบคุม ✅
- ปุ่ม PAUSE หรือ `Esc` หยุด simulation ทั้งฉากและ physics; กลับมาเล่นต่อได้โดยไม่เสียเวลาในเกม
- ตั้ง mouse sensitivity ได้ และ remap ปุ่มจากเมนู pause; ป้องกันการ assign ปุ่มชนกันในโหมดเดียวกัน
- ค่าปุ่มและ sensitivity เก็บใน localStorage แยกจาก campaign save

### 7.2 Non-functional requirements
- **แพลตฟอร์ม:** เป้าหมายหลักคือเบราว์เซอร์เดสก์ท็อป (WebGL + pointer lock); HUD ปรับตาม viewport และตรวจที่ 390×844 แล้ว แต่ยังไม่ได้ยืนยันการควบคุมบนอุปกรณ์มือถือจริงหรือจอย
- **ประสิทธิภาพ:** เป้าหมาย 60 FPS; state ของเกมแยกออกจาก React เพื่อไม่ re-render ทุกเฟรม; HUD อ่านค่าสุ่มตัวอย่างไม่กี่ครั้งต่อวินาที
- **ความกำหนดแน่นอน:** sector และ texture ต่าง ๆ สร้างจาก seed (เล่นซ้ำได้ผลเดิม)
- **คุณภาพโค้ด:** `npm run build` (tsc + vite), `npm run lint` (oxlint), `npm test` (vitest) ต้องผ่าน
- **ไม่พึ่ง asset ภายนอก:** texture, geometry และ shader สร้างด้วยโค้ดทั้งหมด

## 8. Tech stack และสถาปัตยกรรมโดยย่อ

| ส่วน | เทคโนโลยี |
|---|---|
| UI / Framework | React 19 + TypeScript + Vite |
| 3D | three 0.186, @react-three/fiber, @react-three/drei |
| ฟิสิกส์ | @react-three/cannon (cannon-es ใน Web Worker) |
| เอฟเฟกต์ | @react-three/postprocessing (Bloom), GLSL custom shaders |
| ทดสอบ / Lint | Vitest, oxlint (+ type-aware) |

**หลักสถาปัตยกรรมที่สำคัญ**
1. **State นอก React:** `gameStats`, `shipState`, `crewStats` ฯลฯ เป็น module-level mutable store; HUD ดึงค่าเป็นระยะ ส่วน store ที่ต้อง re-render (sector, dock, context menu) ใช้ `useSyncExternalStore`
2. **ตำแหน่งยานอ่านจาก `object.matrix`** ไม่ใช่ `position` (cannon เขียน matrix ตรง ๆ)
3. **Sector ถูกแทนที่ในที่เดิม:** `CELESTIAL_BODIES` ถูก mutate เมื่อ fold เพื่อให้ gravity/autopilot เห็นรายการล่าสุด
4. **Keymap เดียว:** ตาราง binding เป็นแหล่งความจริงทั้งของ input และ HUD hint
5. **Autopilot เป็น task controller:** ฟังก์ชันบริสุทธิ์ input→output ทดสอบได้

โครงสร้างโฟลเดอร์หลัก: `src/game` (ลอจิก+ฉาก), `src/hud` (UI), `src/input` (keymap), `src/scene` (ประกอบ Scene), `src/CrewRegistration.tsx`

## 9. ข้อจำกัดที่ทราบ (Known Limitations)

- ยังไม่ได้เล่นจบแบบเต็มรอบ (spawn → 5 Relics → ลงจอด Earth 2.0) และยังไม่ได้ balance ค่าเศรษฐกิจ/ความยาก
- ใน chase view แบบ pointer lock คลิกวัตถุไม่ได้ ต้องใช้ `T`/เลขหรือ `Esc`
- เข้าวงโคจรดาวเล็กด้วยความเร็วสูงมากอาจล้มเหลว
- "เชื้อเพลิง" ปัจจุบันเป็นแค่ตัวนับวินาทีการใช้เครื่องยนต์ ยังไม่จำกัดการบิน
- แรงโน้มถ่วงกระทำต่อยานเท่านั้น (ไม่กระทบอุกกาบาต/Scrap)
- ยังไม่มีระบบความเสียหายนอกจาก Hull และการเสียบล็อก; Hull 0 ยังไม่มี Game Over
- ไม่มีเสียง/เพลง, ไม่มี save/load, ไม่มีการควบคุมด้วยจอย
- physics chunk `cannon` มีขนาด 585.78 kB (148.94 kB gzip) — ดู PLAN.md ข้อ performance
- ทดสอบ fold 2 ครั้งและตรวจ cleanup ของ texture/meteor tracking แล้ว แต่ยังไม่ได้ profile heap/GPU memory เพื่อยืนยัน memory plateau
