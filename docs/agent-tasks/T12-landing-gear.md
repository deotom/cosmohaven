## ปัญหาที่ตรวจพบแล้ว (lead ตรวจโค้ดและผลวัดเมื่อ 2026-10-04)
1. **สถานะ `landed` ประกาศตอนยานยังลอยอยู่:** `Ship.tsx` (~บรรทัด 486) เช็ก `altitude < LAND_ALTITUDE` โดย `LAND_ALTITUDE = 5` (ความสูงของ *ศูนย์กลาง* ยาน, `autopilot.ts:58`) แต่ยานหนึ่งบล็อกวางบนพื้นจริงที่ความสูงศูนย์กลาง **≈ 0.5** (ผลวัดใน log T7) → ประกาศ "Landed" และปิด autopilot ตอนยานอยู่เหนือพื้น ~4.5 หน่วย แล้วปล่อยให้ตกลงมาเอง (log รอบตรวจ: ความสูง 1.23 → 0.78 → 0.50 หลังขึ้นสถานะ landed)
2. **ไม่มีช่วงล่างเลย:** ตัวยานเป็นกล่องบล็อกที่วางท้องลงพื้น ไม่มีขา ไม่มีการกางขา ไม่มีการยุบตัวรับแรง ทำให้ภาพ "ตกกระแทกพื้นกล่อง" ไม่เหมือนการลงจอด
3. ไม่มีตัวบอกสถานะขา; ไม่มีฝุ่นที่ตำแหน่งขา (ฝุ่นของ T7 ออกจากใต้ยานเป็นภาพรวม)

## เป้าหมาย
ยานมี **ขาลงจอดพื้นฐาน** ที่กางตอนลง ยุบรับแรงตอนแตะ และสถานะ `landed` เกิด **เมื่อขาแตะพื้นจริง** ไม่ใช่ตอนลอยอยู่ — ใช้ได้กับ **ยานที่ผู้เล่นประกอบเองทุกรูปทรง** โดยไม่เพิ่มชนิดบล็อกและไม่เปลี่ยนรูปแบบเซฟ

## สเปก (ค่าเป็นข้อเสนอตั้งต้น — ปรับได้ตามหลักฐานและเหตุผลใน log)
1. **เรขาคณิตขาจากรูปทรงยาน (pure):** `computeGearLayout(blocks)` → หาชั้นล่างสุด (`min y`) ของยาน; วาง **3–4 ขา** ที่มุม/ขอบของรอยเท้าชั้นนั้น (ยานเล็กมาก 1–2 บล็อกใช้ 3 ขาชิดกัน; ยานกว้างใช้ 4 ขาที่มุมนอก); ขายาว `gearLength` (ตั้งต้น **1.5 หน่วย**, เพิ่มตามขนาด/มวลยานได้เล็กน้อย); เท้าเป็นแผ่นรองกว้าง ~0.5; ผลต้องแน่นอน (deterministic) และไม่เกินรอยเท้ายานมากเกิน
2. **กาง/เก็บ:** กางอัตโนมัติเมื่อเข้าเฟส `descent`/ผู้เล่นกด `L` และสูงจากพื้น < ~40 หน่วย (หรือเมื่อ `arrival.phase` เป็น `descent`/`landed`); **เก็บอัตโนมัติ** เมื่อยกตัวขึ้นสูง > ~15 หน่วยหรือออกเฟสลง; ปุ่ม **G** สลับกาง/เก็บด้วยมือ (ห้ามกางในฮังการ์/ขณะ dock — เก็บก่อน dock และก่อน undock ผ่านเสมอ); แอนิเมชันเลื่อนออก ~1 วินาที (ฟังก์ชันบริสุทธิ์ `stepGear(progress, target, dt)`)
3. **ฟิสิกส์สัมผัสพื้น:** ตัดสินใจโดยมีหลักฐานระหว่างสองแนวทาง และบันทึกเหตุผลใน log
   - **A. ตัวชนจริงที่เท้า:** เพิ่ม shape ของแผ่นรองในตัวชนรวม (compound body) เมื่อกางขา — *ระวัง:* การเปลี่ยน shape ของ body ใน worker (กฎ AGENTS: ห้ามสมัคร body ที่อาจถูกลบต่อวัตถุ; useCompoundBody สร้างใหม่เมื่อ args เปลี่ยน) ให้พิสูจน์ว่าไม่ทำให้ worker พังหรือยานกระโดด
   - **B. ช่วงล่างเสมือน (suspension):** ไม่เพิ่ม shape; เมื่อกางขาและ `altitude < gearLength + พื้น` ให้ใส่แรงสปริง-ตัวหน่วงต่อยานตามแนวรัศมีดาว (สัดส่วน `dt*60`, ตามกฎแรง) ทำให้ยานหยุดที่ความสูงนิ่ง = ความสูงขา; ขาถูกวาดยุบตามระยะอัดจริง
   - ต้องเสถียร: ไม่เด้งสั่น/ไม่ NaN/ไม่ทะลุพื้น ที่ความเร็วลง 2/6/12 u/s และ FPS ต่ำ (2 FPS) และสูง; ใช้ `linearDamping()` (`damping.ts`) ตามเดิมสำหรับทุกค่า damping
4. **ลงจอดเมื่อ "ขาแตะ":** `landed` เกิดเมื่อ (ความสูงศูนย์กลาง − ความสูงขา) ≤ ค่าเผื่อเล็ก (~0.15–0.3) และความเร็วเข้าหาดาว ≤ `SAFE_LANDING_SPEED` (12) — ใช้ฟังก์ชันบริสุทธิ์ `isTouchdown(...)`; **ยานต้องนิ่งอยู่บนขาแล้วภายใน ~1 วินาทีหลังประกาศ ไม่ตกต่อ**; ไม่กางขา → ลงท้องได้แต่ **ความเสียหายสูงกว่าและประกาศ landed ที่ความสูงของท้อง** (ไม่มี 5 หน่วยลอย)
5. **รับแรงกระแทก:** ขากางช่วยดูดซับ — ความเสียหายจากการแตะที่ความเร็ว 8–12 u/s น้อยกว่าลงท้อง (ตัวเลขใน log); ความเร็วเกินเพดานยังเสียหาย/ล้มตามตรรกะชนเดิม
6. **autopilot:** `LAND_ALTITUDE` เปลี่ยนจากค่าคงที่ 5 เป็นฟังก์ชันของความสูงขา (พร้อมกันค่าปลอดภัย); `descentController` ต้องเบรกให้ถึงความเร็วแตะ ≤ `TOUCH_SPEED` ที่ความสูงขาจริง; test ตัวจำลอง T8 (`autopilotSim.test.ts`) และ test ลงจอดเดิมต้องผ่านโดยแก้น้อยที่สุดพร้อมเหตุผล
7. **ภาพ:** ขาแบบ strut ยืดหด (ท่อสองท่อนซ้อนกัน) + แผ่นรอง ตามสไตล์ของยาน (วัสดุเดียวกับตัวยาน/ไฟบอกสถานะสีเขียวเมื่อล็อก); instanced หรือ mesh เล็ก ๆ จำนวนน้อย ไม่สร้าง geometry ใหม่ต่อเฟรม; ฝุ่นออกที่แผ่นรองแต่ละขาเมื่อแตะ (ถ้าเข้ากับ `LandingDust` ได้ง่าย)
8. **HUD:** ตัวบอกสถานะขา 3 ค่า — เก็บแล้ว / กำลังกาง / กางแล้วล็อก — บรรทัดเดียวใน panel ที่เกี่ยวกับการลง (ไม่เพิ่มแผงใหม่; รักษากฎ HUD ไม่ซ้อนกัน 1280×720)
