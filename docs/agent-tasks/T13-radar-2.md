## งาน
1. **ภาพเรดาร์ย่อ (ตามข้อ ค):** มุมมองเอียง ~55° (ปุ่มสลับแบน/เอียง), จานแก้วเรืองขอบ, sweep + afterglow (ภาพประกอบ), ไอคอนเวกเตอร์ต่อชนิดขนาดตามรัศมี (log) พร้อมเวกเตอร์ความเร็วของอุกกาบาต, ลูกศรขอบพร้อมระยะสำหรับนอกระยะ, ชิปข้อมูลเป้าหมาย (ชื่อ·ระยะ·ความเร็วเข้าหา·เวลาถึง + ปุ่มลัด Approach/Orbit/Stop), เส้นทาง/วงโคจร preview ของ autopilot ที่กำลังทำงาน; ไม่เพิ่ม dependency; ไม่ re-render React ต่อเฟรม
2. **โต้ตอบ:** hover (ไฮไลต์+ป้ายชื่อ/ระยะ), คลิก = ล็อก/เลือก, ดับเบิลคลิก = คำสั่งเริ่มต้นของชนิด (Approach สำหรับส่วนใหญ่), คลิกขวา/กดค้าง = เมนูคำสั่งเดิม (`openContextMenu`) ตรงจุด, ซูมด้วยล้อ/ปุ่ม `+/-` ระยะ 100/300/1000/3000/ทั้ง sector (จำใน localStorage), จุดซ้อนกันเลือกตัวใกล้/สำคัญก่อน คลิกซ้ำวนเลือก; ทุกอย่างคีย์บอร์ดเข้าถึงได้อย่างน้อยเลือกเป้า/เปิดเมนู
3. **โหมดเคอร์เซอร์:** กด Alt ค้าง (หรือปุ่มอื่นที่ไม่ชน `keymap.ts`) ปล่อยเคอร์เซอร์ชั่วคราวเพื่อใช้เรดาร์ แล้วล็อกใหม่เมื่อปล่อย — **ต้องทดสอบจริงว่า pointer lock ปล่อย/ล็อกซ้ำได้โดยมุมมองไม่กระตุก/เมาส์ไม่หลุดสถานะ**; ถ้าเบราว์เซอร์ปฏิเสธล็อกซ้ำทันที ให้มีทางเลือก (ปุ่มบนจอ) และรายงานใน log
4. **Tactical Map ฉบับแรก (ปุ่มขยาย/`M`):** เต็มจอโปร่งใส: ซ้าย=รายการวัตถุเรียงตามระยะ + ชิปตัวกรอง + ค้นหา (กลุ่มหินเป็น "Asteroid field ×N"), กลาง=แผนที่ 3 มิติหมุน/ซูม/เลื่อน (ลาก/ล้อ) พร้อมวงระยะและ orbit preview, ขวา=รายละเอียด+ปุ่มคำสั่งทั้งหมดของชนิดนั้น (จาก `actionsFor`); ↑↓/Enter/Esc; **ไม่หยุดเกมโดยอัตโนมัติ**; เคอร์เซอร์อิสระขณะเปิด; ปิดแล้วล็อกเมาส์ใหม่
5. **ห้ามรกจอ:** รักษากฎ HUD (ไม่ซ้อนกันที่ 1280×720–2560×1440); เรดาร์ย่อไม่กินที่เพิ่มเกิน ~200 px

## เกณฑ์ผ่าน (วัดได้)
1. test pure: hit-test (พิกเซล→วัตถุใกล้สุดภายในรัศมีคลิก, ลำดับความสำคัญ, วนเลือก, ไม่คืนวัตถุนอกจาน), การฉายเอียง (จุดตรงหน้า/ข้าง/บน-ล่างอยู่ถูกตำแหน่ง, แบนเท่ากับเดิม), ซูม/ระยะ, ลูกศรขอบ (ทิศ/ระยะ), เวลาคำนวณ 500 contacts ไม่เกินงบ (≤ ค่าที่ T3 วัด: median ~2 ms)
2. test เดิม (radarMath 10 ตัว ฯลฯ) ผ่าน; ถ้าเปลี่ยนสัญญา ฟังก์ชันให้อัปเดต test พร้อมเหตุผล
